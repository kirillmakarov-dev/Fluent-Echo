# Fix 02 - Streaming Transcript

## Симптом

Микрофон запускался и Whisper-модель загружалась, но произнесённый текст долго
не появлялся в блоке `WHISPER HEARD`.

## Что показал лог

- Модель `ggml-tiny.en.bin` успешно загрузилась.
- Микрофонные данные доходили до Whisper inference.
- Первый фрагмент имел длину около `990 ms`.
- Whisper отклонил его как вход короче минимальных `1000 ms`.
- Первая полноценная обработка дополнительно требовала времени на прогрев модели.

## Исправление

Streaming step увеличен с `0.75` до `1.25` секунды. Runtime также принудительно
сохраняет минимальный безопасный шаг `1.25` секунды независимо от значения сцены.
Статус интерфейса теперь объясняет, что transcript появляется обработанными
фрагментами, а не печатается посимвольно.

## Что ожидать

После нажатия `START SPEAKING` нужно произнести всю фразу и сделать паузу.
Текст должен появиться после обработки очередного аудиофрагмента. Первый запуск
может быть заметно медленнее последующих из-за загрузки и прогрева модели.

Дополнительные скрипты из English Kingdom для этого не требуются. В standalone
прототипе уже есть microphone stream, Whisper engine, Presenter, matcher,
ScriptableObject упражнения и UI результата.
